# mtcouch
Repositório para TCC

Olá seja bem vindo ao My Training Couth. Este arquivo tem como base para que você possa acessar todas as funcionalidade da nossa aplicação.
    Pedimos com carinho para que você siga estas pequenas instruções para que consiga inicializar com perfeição a aplicação

1. No seu terminal de preferencia, inicie baixando todas as depencias e modulos nescessário:
    1.1 npm install
    1.2 npm openai

2. Em seguida, inicie adicione o banco de dados local no Laragon para a navegação como usuário

3. Inicie o navegador com os comando abaixo e acesse o link do servdor:
    node app.js
