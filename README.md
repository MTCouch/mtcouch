# MTCoutch 📘 Projeto de TCC – Tecnologia da Informação

## 📌 Descrição do Projeto

Este projeto foi desenvolvido como **Trabalho de Conclusão de Curso (TCC)** na área de **Tecnologia da Informação**, com o objetivo de aplicar, na prática, os conhecimentos adquiridos ao longo do curso técnico, envolvendo desenvolvimento de software, banco de dados, lógica de programação e conceitos fundamentais de sistemas computacionais.

A aplicação busca solucionar uma problemática real por meio de uma solução tecnológica moderna, organizada e segura, utilizando boas práticas de desenvolvimento e versionamento.

---

## 🎯 Objetivos

### Objetivo Geral
Desenvolver uma aplicação funcional que demonstre domínio técnico e capacidade de planejamento, implementação e organização de sistemas de informação.

### Objetivos Específicos
- Aplicar conceitos de programação front-end e back-end  
- Utilizar banco de dados para persistência de dados  
- Implementar autenticação e controle de usuários  
- Organizar o código de forma modular  
- Utilizar boas práticas de segurança  
- Versionar o projeto com Git e GitHub  

---

- **Linguagens:**

# 🔧 Instalação
### Clonar o repositório
- git clone https://github.com/MTCouch/mtcouch.git

### Instalar dependências
- npm install

---

### 🔧 Configuração das Variáveis de Ambiente

Crie um arquivo .env na raiz do projeto com o seguinte conteúdo:
AZURE_OPENAI_API_KEY="Sua chave de API!"
AZURE_OPENAI_ENDPOINT="Seu endpoint!"
